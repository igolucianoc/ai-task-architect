# Prompt 08 — Frontend Vue 3

Implemente o frontend principal.

ANTES DE QUALQUER ALTERAÇÃO VISUAL, LEIA `DESIGN.md`.

O `DESIGN.md` é a fonte de verdade. Não altere o arquivo.

## Telas

Criar somente as telas necessárias para demonstrar o produto:

- login;
- dashboard;
- criação de tarefa;
- acompanhamento da execução;
- visualização do resultado;
- avaliação/Quality Gate;
- histórico.

## Requisitos

- Vue 3;
- Composition API;
- TypeScript strict;
- componentes pequenos e coesos;
- estado tipado;
- tratamento de loading/error/empty/success;
- responsividade;
- acessibilidade;
- SSE para acompanhar execução.

Não criar um design system alternativo.

Não usar dados mockados no fluxo principal se a API já estiver disponível.

Os dados iniciais para demonstração devem vir do backend/seeder.

## Qualidade

O frontend deve parecer uma aplicação moderna de produto, e não uma tela técnica de demonstração.

Use exatamente os padrões visuais definidos em `DESIGN.md`.
