# Prompt 13 — README e narrativa de portfólio

Produza a documentação pública final do projeto.

O README deve explicar:

1. O problema;
2. A solução;
3. Por que o projeto existe;
4. O que ele demonstra tecnicamente;
5. Arquitetura;
6. Stack;
7. Fluxo de geração;
8. Fluxo de avaliação;
9. SSE;
10. autenticação;
11. segurança;
12. testes;
13. observabilidade;
14. como executar;
15. seed;
16. exemplos de uso;
17. decisões arquiteturais;
18. limitações;
19. próximos passos.

## Narrativa profissional

A narrativa deve sugerir a evolução:

Software Engineering
→ Architecture
→ Automation
→ LLM Integration
→ Evaluation
→ AI Engineering

Não escrever uma autobiografia no README.

## AI-assisted development

Criar uma seção transparente explicando que o projeto foi desenvolvido com auxílio de IA e que a engenharia humana envolveu:

- definição do problema;
- arquitetura;
- restrições;
- revisão;
- testes;
- validação;
- decisões e trade-offs.

Não alegar que a IA escreveu tudo sozinha.

## Imagens

Se o projeto possuir screenshots, referencie-os de forma organizada.

Não criar imagens falsas de métricas ou resultados.
