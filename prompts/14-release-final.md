# Prompt 14 — Release final e preparação do GitHub

Prepare o repositório para publicação.

Checklist:

- remover arquivos temporários;
- remover secrets;
- revisar `.gitignore`;
- revisar `.env.example`;
- validar Docker;
- validar migrations;
- validar seed;
- executar testes;
- executar typecheck;
- executar lint;
- revisar README;
- revisar ADRs;
- revisar nomes públicos;
- revisar comentários;
- verificar dependências desnecessárias.

Crie uma checklist final de release.

Não faça commit automaticamente.

Ao final, informe exatamente:

- o que está pronto;
- o que ficou fora;
- comandos executados;
- riscos conhecidos;
- sugestão de tag/versão inicial.
